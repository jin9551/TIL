**IP는 인터넷에 연결되는 모든 장치들을 식별할 수 있는 고유 주소로 이해하고 있어. 그런데 이런 IP들이 4가지로 나뉘는다고 하는데 고정 IP와 공인 IP는 뭐야?**


IP 주소가 인터넷 세상에서 장치를 식별하는 '주소' 역할을 한다는 점을 아주 정확히 이해하고 계시네요!

말씀하신 '4가지 IP'는 사실 IP 주소를 구분하는 **두 가지 기준**이 조합되어 만들어집니다.

1. **어디서 접속 가능한가?** (공인 IP vs 사설 IP)
2. **주소가 변하는가?** (고정 IP vs 유동 IP)

질문하신 **공인 IP**와 **고정 IP**가 이 기준에서 각각 어떤 의미를 가지는지 알기 쉽게 설명해 드릴게요.

---

## 1. 공인 IP (Public IP) : 인터넷 세상의 진짜 내 주소

공인 IP는 **전 세계 인터넷 망에서 유일하게 식별되는 공인된 주소**입니다.

* **발급 주체:** KT, SK, LG 같은 인터넷 서비스 제공자(ISP)가 가입자에게 할당해 줍니다.
* **특징:** 인터넷 공간에 직접 연결되어 있기 때문에, 외부(다른 집, 다른 나라)에서 내 컴퓨터나 서버로 찾아올 때 이 공인 IP를 이정표 삼아 찾아오게 됩니다.
* **비유하자면:** 도로명 주소(예: 서울특별시 중구 세종대로 110)와 같습니다. 전 세계 누구나 이 주소를 검색하면 정확히 하나의 건물을 찾아올 수 있습니다.

## 2. 고정 IP (Static IP) : 절대 변하지 않는 주소

고정 IP는 기기를 껐다 켜거나 시간이 지나도 **할당된 주소가 영구적으로 변하지 않는 IP**입니다.

* **특징:** 주로 웹 서버, 이메일 서버, 사내망 접속용 VPN, 외부에서 확인해야 하는 CCTV 등 '남들이 항상 같은 주소로 찾아와야 하는 곳'에 사용됩니다.
* **비용:** 인터넷 통신사에 추가 비용을 내고 신청해야 발급받을 수 있습니다. IP 자원은 한정되어 있기 때문입니다.
* **비유하자면:** 평생 번호가 바뀌지 않는 간판 달린 가게 매장 번호와 같습니다. 손님들이 언제든 헤매지 않고 찾아올 수 있어야 하니까요.

**공인 IP가 전세계에서 사용할 수 있는 IP의 풀이면 고정 ip는 이중 일부분만 누군가 돈을 내고 사용한다는거구나?**

정확합니다! 아주 핵심을 명확하게 짚어내셨어요.

이해하신 대로, 일반적인 인터넷 환경에서 우리가 흔히 말하는 **고정 IP(정확히는 '공인 고정 IP')는 한정된 공인 IP 자원 중 일부를 비용을 지불하고 전용으로 독점하는 개념**이 맞습니다.

**왜 돈을 내고 독점해야 할까요?**
현재 우리가 주로 쓰는 IPv4라는 주소 체계는 전 세계적으로 만들 수 있는 주소가 약 43억 개로 제한되어 있어 이미 고갈 상태입니다.
그래서 통신사(ISP)는 확보한 공인 IP를 효율적으로 쓰기 위해, 일반 가정집에는 컴퓨터나 공유기가 켜져 있을 때만 남는 IP를 빌려주는 **유동 IP** 방식을 사용합니다.

하지만 웹 서비스나 시스템을 운영하려면 방문자나 다른 서버가 항상 똑같은 주소로 찾아와야 하므로, 통신사에 추가 비용을 내고 "이 공인 IP는 회수하지 말고 나만 쓰게 해달라"고 계약하는 것입니다.
(클라우드 인프라를 구축할 때, AWS에서 Elastic IP(탄력적 IP)를 할당받아 인스턴스에 연결하는 것도 바로 이 공인 고정 IP를 고정적으로 확보하는 과정입니다.)

> **💡 참고: 돈을 내지 않는 고정 IP도 있습니다.**
> 외부 인터넷망이 아닌, 집이나 회사 내부의 공유기가 만들어내는 **'사설 IP'** 공간에서는 비용이 발생하지 않습니다. 전 세계 IP 풀을 소모하는 것이 아니기 때문입니다. 예를 들어, 사무실의 공용 프린터나 테스트 장비가 항상 같은 주소를 갖도록 공유기 설정에서 **사설 고정 IP**를 부여하는 것은 언제든 무료로 마음껏 할 수 있습니다.

**그럼 공유기/게이트웨이들은 동일한 ip 주소를 가질 수도 있다는 말이야?**

네, 맞습니다! 아주 예리한 질문입니다.

결론부터 말씀드리면 "어느 쪽(안쪽/바깥쪽)에서 보느냐"에 따라 게이트웨이는 동일한 IP를 가질 수도 있고, 절대 가질 수 없기도 합니다.

게이트웨이(공유기)는 내부망(사설 IP 세상)과 외부망(공인 IP 세상)의 경계에 있는 **'문(Door)'** 역할을 하기 때문에, **반드시 2개의 IP 주소**를 동시에 가집니다.

## 1. 안쪽에서 보는 주소 (사설 IP) : "전 세계 수천만 대가 똑같습니다."

공유기가 집 안의 스마트폰이나 PC와 소통할 때 쓰는 '내부용 주소'입니다.
우리 집 공유기의 안쪽 주소가 `192.168.0.1`이라면, 옆집 공유기도 `192.168.0.1`이고 지구 반대편에 있는 집의 공유기도 `192.168.0.1`일 확률이 아주 높습니다.

* **왜 똑같아도 될까요?** 서로 다른 집의 내부망은 물리적으로 완전히 단절되어 있기 때문입니다. 대한민국의 모든 아파트 건물마다 '101호'가 다 똑같이 존재하지만, 건물 자체가 달라서 서로 헷갈리지 않는 것과 같습니다.

## 2. 바깥쪽에서 보는 주소 (공인 IP) : "절대 똑같을 수 없습니다."

공유기가 인터넷 세상(네이버, 유튜브, AWS 서버 등)과 소통할 때 쓰는 '외부용 주소'입니다.
우리 집 공유기는 바깥을 향해 통신사로부터 `211.x.x.10`을 받고, 옆집은 `121.x.x.50`을 받습니다.

* **왜 다를까요?** 인터넷 세상에서는 전 세계 어디서든 이 주소 하나만 보고 웹페이지 데이터나 영상 데이터를 정확히 배달해야 하기 때문입니다. 아파트의 '101호'는 같아도, 건물의 '도로명 주소'는 전 세계에서 유일해야 택배가 제대로 도착하는 것과 같습니다.
